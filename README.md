# 🌸 HerMind — Women's Mental Wellness Platform

A modern, responsive landing page for a women-focused mental wellness platform focused on accessibility, empathy, and impactful user experience.

## ✨ Features

* Clean and elegant user interface
* Fully responsive design (mobile + desktop)
* Structured sections including:

  * Problem statement
  * Features & services
  * Business model
  * Testimonials
  * Pricing plans
* Smooth animations and transitions
* Mobile-friendly navigation

## 🛠️ Tech Stack

* HTML5
* CSS3 (custom styling, no frameworks)

## 🎯 Purpose

This project showcases UI/UX design for a digital platform aimed at improving women's mental wellness through accessible and thoughtful design.

## ⚠️ Note

This is a frontend concept / landing page and does not include backend functionality.

## ❤️ Made With

Built with a focus on design, usability, and real-world impact.
